Pipeline notes

The UI is static, but the data flow mirrors the local ML pipeline.

  1. Precompute Read MINDsmall, build news embeddings, metadata and user history artifacts.
  2. Train Build CTR samples, train the MLP reranker, save model and training report.
  3. Recommend Retrieve candidates by cosine similarity, rerank with CTR, then diversify with MMR.
